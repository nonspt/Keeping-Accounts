# 我的账本 PWA

本地优先记账 PWA。

## 使用

首次打开后可以使用浏览器的“添加到主屏幕”安装。账目保存在当前设备浏览器中，支持离线打开；可在统计页底部导出 JSON 备份。

## 当前功能

- 首页展示本月支出、本月预算结余和预算进度。
- 支持支出、转账两种账目类型。
- 支持账目编辑、删除，以及在全部账目弹窗中按时间和类别筛选。
- 支持分类排行和每日支出趋势统计。
- 账户选项为微信、支付宝、云闪付、现金、银行卡、其他。
- 统计页底部提供数据管理：导出 JSON、导入 JSON、清空本地数据。
- 支持人民币默认货币和月度预算设置。
- 支持 JSON 导出与导入，核心数据使用 IndexedDB 本地保存。
